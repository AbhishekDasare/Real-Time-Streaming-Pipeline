# Real-Time-Streaming-Pipeline

## Overview

This project demonstrates a real-time data streaming pipeline using PySpark Structured Streaming. Customer transaction data is continuously processed and written to a streaming output layer for analytics and reporting.


## Technology Stack

- Python
- PySpark
- Apache Spark
- Structured Streaming
- Git
- GitHub


## Data Flow

1. Producer generates customer transaction records.
2. PySpark Structured Streaming reads incoming data.
3. Validation and transformation logic is applied.
4. Processed records are sent to the consumer layer.
5. Streaming output is generated for analytics.
